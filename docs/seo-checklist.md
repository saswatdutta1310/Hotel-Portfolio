# SEO checklist

- Google Business Profile created, verified, and linked from the site
- Name, address and phone identical everywhere (NAP consistency)
- Unique title and meta description for every hotel page
- schema.org Hotel structured data on every hotel page
- sitemap.xml and robots.txt published
- Open Graph image so links look good on WhatsApp and Instagram
- Lighthouse 90+ on mobile (performance, accessibility, SEO)
- Descriptive alt text on every image
- Own domain pointed to the site, HTTPS enabled
- Submit the sitemap in Google Search Console
